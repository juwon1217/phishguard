# Scoring system
Scoring System은 다음과 같은 논리를 따른다.<br>
x1 : 지인 및 가족 사칭  
	키워드 : 엄마,아빠,동생,언니,오빠,친구,자녀,선배    
x2 : 기관 및 기업 사칭 변수  
	키워드 : 검찰, 수사관, 서울지검, 금융감독원, 금감원, 과장, 대리, 팀장, 질병청  

x3 : 금전 및 상품권 요구 변수
	키워드 : 상품권, 문화상품권, 핀번호, 이체, 송금, 현금, 대출상환, 선입금, 보증금
x4 : 기술적 행동 유도 변수
	키워드 : 앱 설치, 어플, apk, 링크, URL, 클릭, 다운로드, QR코드, 원격, 팀뷰어
x5 : 긴급성 및 공포 조장 변수
	키워드 : 즉시,당장,마감, 소진,출두,고발,영장,구속,유포, 전 재산
x6 : 미끼/유인 키워드
	키워드 : 정부지원금, 재난지원금, 4차 추경, 고수익, 알바, 부업, 재택, 이벤트, 최저가
x7 : 로맨스/ 감정 호소
	키워드 : 해외 파병, 군인,선물, 배송비,상속, 연인
tf-idf로 분류한 후, 점수를 xgboost로 매긴다.
